# GhostPrint for Linux

A separate Linux desktop package is planned but is not currently built or tested. Do not treat this folder as an installable Linux application.

The repository retains its Python command-line auditor, which may be usable on Linux with the required Python packages and compatible MVT/libimobiledevice tools installed. That is a developer/source workflow, not a supported one-click Linux distribution. A future Linux package should have its own dependency and backup-creation guidance.
